# Python Lab Assignment

This folder contains the five Python programs for the lab assignment.

1. `Q1_Student_Result.py` — Student results and grades
2. `Q2_Word_Analysis.py` — Sentence and word analysis
3. `Q3_Shopping_Bill.py` — Shopping bill and discount
4. `Q4_Calculator.py` — Menu-based calculator
5. `Q5_Restaurant_Order.py` — Restaurant ordering system

## Run in PyCharm
Open the folder in PyCharm, open any `.py` file, and click the green Run button.
The programs that ask for input should be run in the Run console.
